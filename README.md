# This is an Agentic AI automation workflow built using langchain, langgraph and several other google products as an entry for Winter Solstice Hackathon.

### Technologies used:
- **Langchain** + **Langgraph** for Agent
- **Ollama** as server for running **Gemma 3** which is going to be our local LLM
- Written in **Python3**
- **Tavily Search API** to fetch structured data from the web if needed
